# go-server

yeah it's a go server idk what else to tell you

## run it

```bash
go build && ./go-server
```

then hit up http://localhost:8080

## what's in it

- `/` - serves static files from `static/`
- `/hello` - says hello back, very polite
- `/form` - there's a form, you can submit stuff

that's pretty much it
